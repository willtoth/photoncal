Archive SHA-256: {{SHA256}}

Manual download / low-memory alternative

Save every part below into a new, empty directory. In that directory, concatenate them in filename order. On Linux/macOS: 

cat photoncal-source.tar.gz.*.part > photoncal-source.tar.gz
shasum -a 256 photoncal-source.tar.gz
tar -xzf photoncal-source.tar.gz

Compare the hash with the value above before extracting. Checksum file · Part manifest
